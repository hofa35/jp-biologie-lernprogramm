# Lernprogramm Biologie – Jan Philipp

Interaktives Lernprogramm für Klasse 8 (Biologie) zu den Themen Ökosysteme,
Nahrungsbeziehungen, Fotosynthese und Blattaufbau, mit anschließendem
ausdruckbaren Test.

- `index.html` – interaktive Lernseite mit fünf Modulen (Ökosysteme,
  Nahrungsbeziehungen, Fotosynthese, Blattaufbau, Rückblick)
- `test.html` – Test zum Ausdrucken und handschriftlichen Ausfüllen (ca. 15–20 Minuten)
- `bilder/` – verwendete Abbildungen aus dem Biobuch sowie eigene Fotos/Zeichnungen

Läuft direkt im Browser, ohne Installation – auch auf iPad/Tablet.
